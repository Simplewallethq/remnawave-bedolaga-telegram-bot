# Конструктор VPN-ботов

Отдельный Telegram-бот, в котором любой создаёт своего VPN-бота. Работает
внутри процесса основного бота и поверх платформы владельцев (см.
«Платформа владельцев» в `COPYCAT_BRANDING.md`): те же аккаунты владельцев,
боты, цены, заработок и заявки на вывод. Владелец, подключивший ботов в
боте-платформе (@dostupoffbot), видит их в конструкторе, и наоборот.

- **Бот** — быстрый старт: главный экран с кнопкой «Открыть приложение» и
  мастер создания в чате (токен → поддержка → обложка → запуск). После запуска
  бот снова ведёт в приложение.
- **Мини-апп** — всё управление: боты, статус, поддержка, обложка, цены,
  удаление, заработок, кошелёк TRC-20, заявки на вывод. Там же свой мастер
  создания.

## Где что

| Что | Где |
|---|---|
| Запуск, вебхук, монтирование в веб-сервер | `app/constructor/runtime.py` |
| Аккаунт владельца, проверка токена, запуск бота | `app/constructor/service.py` |
| Экраны бота | `app/constructor/screens.py`, `handlers.py`, `ui.py` |
| API мини-аппа | `app/constructor/api.py` |
| Мини-апп (React + Vite) | `constructor_web/` — собирается в Dockerfile |
| Обложки экранов бота и стандартная обложка ботов владельцев | `assets/constructor/` |

У конструктора свой `Dispatcher`: VPN-обвязка основного (регистрация,
подписки, техработы, обязательный канал) ему не нужна. FSM-хранилище общее
(Redis), ключи разведены по id бота: там лежат id единственного сообщения
бота, текущий экран и черновик мастера.

Если конструктор не поднялся (неверный токен, нет сети), основной бот
работает без него — в логе предупреждение.

## Адреса

Всё в веб-сервере основного бота (порт `WEB_API_PORT`):

- `<WEBHOOK_URL><WEBHOOK_PATH>/constructor` — вебхук бота (секрет тот же,
  `WEBHOOK_SECRET_TOKEN`); в polling-режиме — свой поллинг;
- `/constructor/` — мини-апп (`CONSTRUCTOR_WEBAPP_STATIC_PATH`);
- `/constructor/api/…` — API мини-аппа. Авторизация —
  `Authorization: tma <initData>`, подпись проверяется токеном
  конструктора.

Мини-апп собран с относительными путями: работает и по
`https://<хост>/constructor/`, и на отдельном домене, который nginx
проксирует на `/constructor/`:

```nginx
server {
    listen 443 ssl;
    server_name cats.example.com;
    client_max_body_size 12m;          # обложки до 10 МБ
    location / {
        proxy_pass http://remnawave_bot_unified/constructor/;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## Включение

1. В `.env`: `CONSTRUCTOR_BOT_TOKEN`, `CONSTRUCTOR_WEBAPP_URL` (https-адрес
   мини-аппа), при желании `CONSTRUCTOR_EXAMPLE_BOT_URL`. Нужен
   `OWNER_PLATFORM_BOT_ID` — без платформы конструктор выключен.
2. Перезапуск бота. Конструктор ставит себе вебхук, команду /start и кнопку
   меню «Открыть». Токеном не должен пользоваться никто другой: вебхук
   перехватит апдейты у прежнего обработчика.
3. Проверить: /start в конструкторе, создание тестового бота, приложение.
4. Перевести бота-платформу: `OWNER_PLATFORM_REDIRECT_TO_CONSTRUCTOR=true` —
   «Создать VPN бота», «Создать своего VPN бота» и меню владельца в
   @dostupoffbot ведут в конструктор. Откат — `false`. Старые экраны
   платформы продолжают работать для уже отправленных сообщений.

## Правила

Все — платформы владельцев (`owner_platform_service`), конструктор их не
дублирует:

- бот подключается токеном (getMe); у бота чужой вебхук — предупреждение и
  подтверждение; включённый бот не подключить, свой выключенный —
  возвращается со всеми настройками, чужой выключенный — «подключён другим
  владельцем»; основной бот, платформа и сам конструктор запрещены; лимит —
  `OWNER_MAX_BOTS`;
- обложка перекодируется в JPEG (`save_picture_bytes`), без своей —
  `assets/constructor/demo.png`, а не картинка основного бренда;
- цены — месячные Solo/Plus/Pro с минимумами, длинные периоды — множителями
  `OWNER_PRICE_PERIOD_MULTIPLIERS`; скидок нет;
- заработок, вывод в USDT TRC-20, курс и комиссия — как в платформе;
  о выплате владелец узнаёт в конструкторе, а если не открывал его — в
  боте-платформе.

## Мини-апп локально

```bash
cd constructor_web
npm ci
npm run dev        # http://localhost:5173, /api → http://127.0.0.1:8080/constructor/api
```

Без Telegram API отвечает 401 — открывать из Telegram (например, через
HTTPS-туннель на dev-сервер).
